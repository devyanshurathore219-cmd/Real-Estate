# Luxury Real Estate Showcase

A motion-driven real estate portfolio featuring custom scroll snap animations and luxury property layouts.

### Key Highlights
* Focus-isolation grid hover effects (non-selected items fade out).
* Horizontal snap-scrolling editorial grids.
* Modal lightbox galleries for high-resolution property viewing.
* Custom SVG stroke drawings.

### Tech Stack
* HTML5
* Tailwind CSS
* JavaScript (ES6)

### Getting Started
Open `index.html` directly in your browser, or run a local live server.
